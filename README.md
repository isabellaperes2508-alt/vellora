# Vellora — demonstração

Demonstração pública do **Vellora**, gestão operacional para lojas de veículos seminovos e usados:
estoque, entradas e saídas, pendências, comunicação de venda, comissões e metas.

**Acesse:** https://isabellaperes2508-alt.github.io/vellora/

- Funciona em qualquer navegador, no computador e no celular, e pode ser **instalada como aplicativo**
  (botão "Instalar app"; no iPhone: Compartilhar → Adicionar à Tela de Início).
- Todos os dados são **fictícios** e ficam só no navegador de quem acessa; recarregar a página volta ao início.
- O Vellora é uma ferramenta de gestão da consultoria. **Não é o sistema oficial RENAVE** e não se apresenta
  como SERPRO, SENATRAN ou DETRAN.

Este repositório contém apenas a página publicada (gerada a partir do projeto principal pelo
`demo/montar_site_publico.py`). Não contém dados reais, senhas, chaves ou certificados.
